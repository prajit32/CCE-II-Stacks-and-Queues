# CCE II: Git and GitHub Repository

## Unit IV: Stacks and Queues

### 1. Introduction

This repository contains C++ programs demonstrating the implementation of stacks and queues using arrays and linked lists. It is created as part of the CCE II assignment for Unit IV.

### 2. Objectives

* To understand the concepts of stacks and queues.
* To implement stack operations using arrays and linked lists.
* To implement queue operations using arrays and linked lists.
* To understand version control using Git and GitHub.
* To organize and maintain source code in a GitHub repository.

### 3. Programs Included

#### A. Stack

1. `stack_array.cpp`: Implements a stack using an array.
2. `stack_linked_list.cpp`: Implements a stack using a linked list.

**Stack Operations:**

* Push: Inserts an element into the stack.
* Pop: Removes the top element from the stack.
* Display: Displays the stack elements.

#### B. Queue

1. `queue_array.cpp`: Implements a queue using an array.
2. `queue_linked_list.cpp`: Implements a queue using a linked list.

**Queue Operations:**

* Enqueue: Inserts an element into the queue.
* Dequeue: Removes an element from the queue.
* Display: Displays the queue elements.

### 4. Software Requirements

* C++ compiler
* Visual Studio Code or Code::Blocks
* Git
* GitHub account

### 5. How to Compile and Run

**Stack using Array**

```bash
g++ Stack/stack_array.cpp -o stack_array
./stack_array
```

**Stack using Linked List**

```bash
g++ Stack/stack_linked_list.cpp -o stack_linked_list
./stack_linked_list
```

**Queue using Array**

```bash
g++ Queue/queue_array.cpp -o queue_array
./queue_array
```

**Queue using Linked List**

```bash
g++ Queue/queue_linked_list.cpp -o queue_linked_list
./queue_linked_list
```

**Note:** On Windows, run the generated executable using its `.exe` filename.
